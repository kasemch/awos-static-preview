# NEXA Brand Decision Record v1.0

Status: APPROVED / FROZEN BRAND DIRECTION
Date: 2026-09-30

## Brand architecture
Product name: NEXA
Descriptor: Academic Work Intelligence Platform
Architecture attribution: Powered by AWOS Architecture

AWOS remains the internal/technical architecture name. This decision does not authorize renaming repositories, databases, API namespaces, schemas, environment variables, or historical evidence.

## Approved visual direction
Selected concept: 05 — Workflow Path (Dynamic).
Meaning: continuous academic work flow, connection, progression and reuse across Capture → Workflow → Evidence.
Visual intent: academic, intelligent, minimal, connected. Avoid generic robot/brain AI symbolism.

## Approved use
NEXA is the user-facing product/brand layer. Use the descriptor with first/official presentation. “Powered by AWOS Architecture” is secondary attribution and must not visually compete with NEXA.

## Prototype application
Development preview may apply the NEXA name and textual lockup. Production/public launch, final vector master artwork, trademark/domain claims, repository/database renaming and external integrations remain separate Human Gates.

## Change control
Major changes to the selected Workflow Path logo direction or brand architecture require an explicit design change decision. Responsive sizing, accessibility, spacing and implementation refinements that preserve the selected identity do not reopen the design decision.
